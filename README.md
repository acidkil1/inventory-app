\# 📦 Программа инвентаризации



Десктопное приложение для учета и управления предметами с графическим интерфейсом.



\## 🚀 Функционал

\- Добавление, редактирование и удаление записей.

\- Поиск по базе данных.

\- Импорт данных из Excel (`inventory\_import.xlsx`).

\- Сохранение данных в SQLite (`inventory.db`).

\- Сборка в исполняемый файл `.exe` (скрипт `build\_exe.bat`).



\## 🛠️ Технологии

\- Python 3

\- Tkinter (GUI)

\- SQLite3 (хранение данных)

\- OpenPyXL / Pandas (работа с Excel)



\## 📦 Как запустить

1\. Установите Python 3.

2\. Установите зависимости: `pip install -r requirements.txt` (если есть).

3\. Запустите: `python inventory.py`
